Herramientas esenciales para desarrollar aplicaciones web

Un editor de código, un navegador moderno, un servidor local y las herramientas de desarrollador son la base de cualquier proyecto web. Esta página es mi primer proyecto y documenta ese entorno de trabajo.

Ver herramientas Aprender en MDN Web Docs ↗

Las cuatro herramientas fundamentales

Cada herramienta cumple una función distinta, y juntas forman el flujo de trabajo de escribir, ejecutar, probar y depurar.

📝

Editor de código

Permite escribir HTML, CSS y JavaScript con resaltado de sintaxis, autocompletado y extensiones. Ejemplo: Visual Studio Code.

🌐

Navegador web

Interpreta y muestra el código del proyecto tal como lo verá el usuario final. Ejemplos: Google Chrome, Firefox, Edge.

🖥️

Servidor local

Sirve los archivos desde tu propio equipo para probar el proyecto como si estuviera en internet. Ejemplos: Live Server, XAMPP, Node.js.

🛠️

Herramientas de desarrollador

Inspeccionan elementos, estilos, red y consola para detectar y corregir errores. Se abren con la tecla F12.

Estructura del proyecto

Organizar los archivos desde el inicio facilita el mantenimiento y el trabajo en equipo. Este proyecto separa la estructura, el estilo y el comportamiento:

  • index.html: estructura y contenido de la página.
  • css/styles.css: diseño y apariencia visual.
  • js/main.js: interactividad y comportamiento.
  • img/: imágenes y recursos gráficos.
